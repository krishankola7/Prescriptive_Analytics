# Prescriptive_Analytics
A supply chain optimization project ,

Sustainable **Supply Chain Optimization ** – GreenGlow Cosmetics
I developed a robust optimization model for GreenGlow Cosmetics’ global supply chain using Python. The project combined Mixed-Integer Linear Programming (MILP) and Stochastic Programming to minimize costs, reduce CO₂ emissions, and maximize service levels across six international regions under uncertain demand and supplier variability. Key contributions included sensitivity analysis, sustainability metrics, and actionable recommendations such as scaling production at the Asia plant and prioritizing low-cost, low-emission suppliers. The model integrated real-world constraints like emissions caps, production limits, and transport bottlenecks. I also visualized insights using heatmaps, bar charts, pie charts, and geospatial maps
